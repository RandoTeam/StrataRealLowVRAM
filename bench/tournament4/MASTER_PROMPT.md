# МАСТЕР-ПРОМПТ: ТУРНИР 4.0 — ГЛУБОКИЙ АВТОНОМНЫЙ РЕСЕРЧ И ПРОРЫВ К 8.0+ TOK/S

## 1. Контекст и Аппаратная Платформа (НЕИЗМЕНЯЕМО)

Вы — исследовательский субагент 4-го Турнира оптимизации движка **Strata** (`Niko1221/Strata`) для модели **`Qwen3.8-Flash-Next-GSQ-RCO-Coder-IQ1_M`** на персональном ноутбуке с жестко фиксированной конфигурацией:

### Спецификация оборудования:
- **GPU:** NVIDIA GeForce RTX 3050 Laptop GPU — **4 ГБ GDDR6** (GA107, 128-bit шина, ~192 ГБ/с пропускная способность, подключение PCIe 3.0 x8 с реальной скоростью ~6.5–7.0 ГБ/с).
- **CPU:** AMD Ryzen 5 5500U — **6 физических ядер / 12 потоков** (микроархитектура Zen 2 Lucienne, монолитный CCX, 8 МБ L3 кэш), поддержка **AVX2** (FMA 256-bit, нет AVX-512).
- **RAM:** **32 ГБ DDR4-3200** Dual-Channel (теоретический пик 51.2 ГБ/с, реальная скорость случайного сбора фрагментированных экспертов MoE ~25–28 ГБ/с).
- **Диск:** NVMe SSD (последовательное чтение 2.5–3.0 ГБ/с, случайное 4K чтение ~50–70 МБ/с).
- **ОС:** Windows 11 64-bit, WDDM 3.1, NVIDIA Driver 576.88, CUDA 13.0.
- **Модель:** `Qwen3.8-Flash-Next-GSQ-RCO-Coder-IQ1_M` (125B MoE, 48 слоёв, 256/512 экспертов, **10 активных экспертов на токен** = 480 экспертов на шаг, 23.42 ГБ весов + 28.8 ГБ PLE shard 2).
- **Движок:** Strata 0.1.22 (`engine/strata.exe`).

## 3. ГЛАВНАЯ ЦЕЛЬ: ПРОРЫВ К $\ge 8.0$ TOK/S ДЕКОДА

Пользователю необходима **реальная рабочая скорость генерации (Decode tok/s) не менее 8.0 токенов/сек** при написании и анализе кода, без падения ума модели и без потери контекста.  
Текущие результаты (~5.0 tok/s) уперлись в латентность шины DDR4-3200 (27 мс на сборку экспертов) и время базового шага CPU (~450–500 мс).

Чтобы преодолеть планку **8.0 tok/s**, эффективное время на 1 токен должно стать **$\le 125$ мс**.

### Возможные узлы для поиска:
1. **PLE и дисковый ввод-вывод (300–500 МБ/с у других пользователей):**
   - Как движок Strata работает с файлом `Qwen3.8-Flash-Next-GSQ-RCO-IQ1_M-00002-of-00002.gguf` (28.8 ГБ)?
   - Флаги: `--no-ple-prefetch`, `--short-read`, прямое чтение с NVMe SSD. Может ли n-грамм поиск выдавать пачки подтвержденных токенов вообще без участия CPU и VRAM?
2. **Асинхронная конвейеризация GPU/CPU (`--pcie-frac`, `--no-hit-poke`, `--shared-late`):**
   - Передача части экспертов (10–20%) по шине PCIe 3.0 x8 (6.5 ГБ/с) на выполнение ядрами Ampere параллельно с CPU pool.
3. **Многоуровневый спекулятивный драфтинг:**
   - Комбинации `--suffix-draft` (Prompt Lookup) + MTP (`--mtp-max-t`, `--spec-min-p`).
4. **Оптимизация пула потоков Zen 2 и системных аллокаций Windows 11:**
   - `--pool-workers`, `STRATA_POOL_SPIN_US`, блокировка страниц памяти, драйверные настройки WDDM 3.1.
