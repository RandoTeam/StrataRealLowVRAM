# Аналитический отчет: Qwen3.6-35B-A3B vs. Qwen3.8-Flash-Next

Данные зафиксированы для архива. Дальнейшие ресурсы на 35B не тратятся, фокус направлен на Qwen3.8-Flash-Next.

## Сравнительная матрица архитектур

| Метрика | Qwen3.6-35B-A3B | Qwen3.8-Flash-Next (Coder IQ1_M) |
| :--- | :--- | :--- |
| **Общие параметры** | 35.3 млрд | 125 млрд (+ PLE N-gram 28.8 ГБ) |
| **Активных параметров на токен** | ~3.0 млрд | ~6.0 млрд |
| **Архитектура экспертов** | 256 экспертов (Top-8 routed + 1 shared) | 128 экспертов на слой (Top-10 routed) x 48 слоев |
| **Объем выборки весов на токен** | ~1.1–1.5 ГБ | ~0.98 ГБ (в IQ1_M Coder) |
| **SWE-bench Verified (Код PR)** | 73.4% | **84.2%** |
| **LiveCodeBench v6 (Алгоритмы)** | 80.4% | **91.9%** |
| **GPQA Diamond (Научная логика)**| 86.0% | **91.7%** |
| **Скорость на Ryzen 5500U + 4GB GPU** | 7–8 tok/s (база) / 10–11 tok/s (MTP) | 4.5–5.5 tok/s (база + MTP в Strata) |
| **Слоев в VRAM RTX 3050 4GB** | 4–5 слоев | 0 экспертов (только Attention + MTP) |

## Вывод
Qwen3.6-35B-A3B может выдать 10–11 tok/s за счет вдвое меньшего числа активных параметров, но уступает Qwen3.8-Flash-Next на 10–13% во всех тестах глубокого кодинга и рассуждений. Решением пользователя развитие ветки 35B заморожено.
